# Ferixdi AI — Охваты на AI

Статический учебный сайт курса, собранный под GitHub Pages.

## Что внутри
- 16 модулей и 131 подробный урок для новичка
- 15+ практических заданий с отправкой результатов в @ferixdiii
- каждый урок содержит подробный разбор минимум из 30 предложений
- FERIXDI VIDEO FACTORY v40.0 как основной текущий мастер-промпт
- отдельный архив v15 / v23.1 / v32 / v33 checkpoint
- Universal Smartphone Photorealism Engine
- VOICE PERFORMANCE
- Video Recreation / Forensic / Memes Video-to-Video
- статьи, PDF, скриншоты и видеоуроки
- Apify-аналитика, регулярность, постоянные персонажи
- Syntx → AI-инструменты → более дорогие модели монетизации
- Wellside / недвижимость как отдельный практический трек

## Актуальность
Названия моделей, лимиты, цены, кредиты, семейные режимы, доступность сервисов и интерфейсы меняются быстро. Материалы фиксируют практику на момент записи. Перед покупкой доступа или настройкой нужно сверять актуальное состояние сервиса.

## Доступ
Пока репозиторий публичный, исходники курса и файлы тоже публичны. Клиентский пароль в HTML не является реальной защитой. Для платного закрытого доступа нужен приватный репозиторий/хостинг и серверная авторизация либо отдельный сервис доступа.

## GitHub Pages
GitHub Pages для репозитория включён через стандартную публикацию из ветки. Источник сайта — `main` / root. Отдельный custom workflow не нужен.
